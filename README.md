# Tabla Nutricional

Página HTML para mostrar directamente la etiqueta nutricional, sin mostrar la interfaz de GitHub.

## Publicación con GitHub Pages

1. Sube `index.html` y `etiqueta_nutricional.png` al repositorio.
2. En GitHub entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda la configuración.

La página quedará disponible en:

`https://nagomezru.github.io/tablanutricional/`
